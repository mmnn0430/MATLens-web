# 기기별 복수 파일 업로드·개별 분석·비교 기능 사양서 (docs/MULTI_FILE_UPLOAD_AND_COMPARISON_SPEC.md)

## 1. 개요 및 설계 원칙

본 문서는 MatLens의 8개 분석 기기(XRD, SEM, UTM, Hall, LFA, FT-IR, DSC, TGA) 화면에서 복수의 원시 측정 파일을 한 번에 업로드하고, 각 파일을 독립적인 측정 데이터로 파싱·분석·저장하며, 동일 화면에서 다중 곡선 중첩 및 정량 비교표를 통해 한눈에 비교할 수 있는 기능을 정의합니다.

### 핵심 설계 원칙
1. **데이터 독립성 (Data Independence)**:
   - 복수 파일을 하나의 긴 배열로 합쳐서 평균내거나 왜곡하지 않는다.
   - 각 파일은 독립적인 고유 ID(`file_id` 또는 `measurement_id`)를 부여받고 개별 파싱 및 분석 파이프라인을 거친다.
   - 파일별 조건(시험편 단면적/표점거리, 시료 질량, 스케일 바, 온도 등)은 파일마다 독립적으로 관리되며, 한 파일의 분석 실패가 다른 정상 파일에 영향을 주지 않는다.
2. **비교 시각화 무결성 (Visualization Integrity)**:
   - 복수 곡선을 겹쳐 그릴 때 원본 수치를 임의로 이동/보간/평활화하지 않는다.
   - 정규화(Normalization) 또는 시각적 오프셋(Offset)이 적용된 경우 UI 상단에 명확한 토글 및 상태 배지를 표기한다.
   - 곡선별 색상 구분, 범례(Legend), 곡선별 On/Off 토글, 마우스 호버 툴팁(파일명, x축, y축, 단위)을 기본 제공한다.
3. **통합 리포트와의 유기적 연계**:
   - 배치 업로드 및 분석된 개별 파일의 결과는 데이터베이스에 독립 레코드로 자동 저장되어, 통합 리포트의 2단계 선택 화면에서 파일 단위로 1개, 2개, 또는 전체를 선택할 수 있다.

| **FT-IR** | `.csv`, `.txt`, `.dat` | 신호 타입(%T/Abs), 굴절률($n$), 간섭무늬 파수 범위, 피크 감도 | Wavenumber vs Transmittance / Absorbance 중첩 | 주요 특성 흡수 밴드($cm^{-1}$), 투과율(%), 간섭무늬 기반 물리적 박막 두께($\mu m$) |
| **DSC** | `.csv`, `.txt`, `.dat` | 시료 질량($mg$), 열류 단위($mW$, $W/g$), 표준 융해열, 세그먼트 | Temperature vs Heat Flow 곡선 중첩 | 유리전이온도($T_g$), 결정화온도($T_c$), 융점($T_m$), 융해 엔탈피($\Delta H_m$), 결정화도($\chi_c$, %) |
| **TGA** | `.csv`, `.txt`, `.dat` | 초기 질량($mg$), 가스 전환 온도($^\circ C$), 백분율 입력 여부 | Temperature vs Mass Loss(%) 및 DTG 도함수 곡선 중첩 | 분해 시작온도($T_{onset}$), 최대 분해온도($T_{max}$), 단계별 질량 감소율(%), 최종 잔류율(%) |

## 3. UI 컴포넌트 상세 설계

### 3.1 공통 다중 파일 드롭존 및 파일 큐
- 드래그 앤 드롭 또는 파일 탐색기(`<input type="file" multiple>`)를 통한 일괄 파일 수령.
- 파일 목록 큐:
  - 파일명, 크기, 연결된 시료명
  - 분석 진행 상태 배지 (`대기 중` / `분석 중` / `완료` / `오류`)
  - 개별 파라미터 팝오버 / 설정 버튼
  - 개별 파일 제외 (`X`) 버튼
  - 일괄 분석 실행 (`선택 파일 전체 분석`) 및 개별 재분석 버튼

### 3.2 중첩 비교 뷰 (Comparative Overlay View)
- 상단 탭: `[중첩 비교 모드 (Overlay)]` vs `[개별 파일 상세 모드 (Individual)]`
- Plotly 기반 반응형 인터랙티브 차트:
  - 곡선마다 뚜렷한 팔레트 색상 부여 (MatLens 정밀 블루, 에메랄드, 오렌지, 퍼플, 레드 등 10색 순환)
  - 곡선 범례 클릭 시 실시간 토글 (Show/Hide)
  - x/y축 스케일 자동 정렬 및 호환성 체크 (단위가 다르면 경고 배지 표시)
- 비교 테이블:
  - 파일별 핵심 정량 지표 나란히 비교
  - 행마다 최고값(Max), 최저값(Min) 또는 평균/표준편차(동일 시료 반복 측정인 경우에 한해 활성화) 표시

## 4. 백엔드 및 저장 구조 연동

1. 파일 파싱 및 분석 시 각 파일마다 `sample_measurements` 및 `sample_analysis_results`에 레코드를 독립 생성.
2. `measurement_id`와 `analysis_id`를 부여하여 개별 파일의 결과가 즉시 DB에 영구 저장됨.
3. 동일 세션에서 일괄 처리된 파일들은 배치 태그 또는 동일 `sample_id`로 연결되어 통합 리포트에서 손쉽게 한꺼번에 또는 개별적으로 선택 가능.
