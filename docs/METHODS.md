# 분석 방법과 적용 범위

## XRD

입력은 2θ(도), 강도입니다. UTF-8/CP949, 쉼표/탭/세미콜론/공백, 헤더 유무를 처리합니다. 선택된 두 열의 결측값·무한대는 제외하고 중복 각도는 평균합니다. 불균일 각도 간격(CV > 0.02)은 같은 데이터 개수의 균일 격자로 선형 보간합니다. 원본 파일을 별도 저장하며 처리 내역을 반환합니다.

ALS 목적함수는 가중 잔차 제곱과 2차 차분 곡률 벌점의 합입니다. 기본 λ=10⁶, 비대칭 가중치 p=0.01, 반복 12회입니다. 상수 신호에는 배경을 원본으로 설정합니다. 보정 강도를 임의로 음수 절삭하지 않습니다. Savitzky–Golay는 피크 검출에만 사용하며 피팅은 평활화 전 배경 보정 신호를 이용합니다.

국소 피크를 Gaussian + 상수 오프셋으로 피팅합니다. FWHM=2√(2ln2)σ, 면적=Aσ√(2π). R²≥0.9, 폭≥2 스텝, 인접 피크와 분리된 경우만 Scherrer 계산에 사용합니다. 미분해 겹침, 텍스처, 이방성, Kα 이중선 모델링과 Voigt 장비 함수는 구현하지 않았습니다. 피팅 면적은 국소 Gaussian의 전체 적분 근사입니다.

Scherrer: D=Kλ/(βcosθ). λ는 Å에서 nm로 변환하며 β는 2θ FWHM의 라디안 값입니다. 기기 보정은 Gaussian 가정 아래 β_sample²=β_measured²−β_instrument²를 사용합니다. 측정 폭이 기기 폭 이하이면 계산하지 않습니다. 보정 데이터가 없으면 ‘기기 선폭 미보정’ 표시를 유지합니다. 추정값은 크기 외 변형·결함의 영향이 포함될 수 있으며 SEM 입자 직경과 동등하지 않습니다. 요약은 유효 피크별 D의 중앙값입니다.

## 기준 패턴 매칭

각 CIF의 실제 구조에 대해 입력 파장과 관찰 범위의 이론 패턴을 pymatgen으로 생성합니다. 상대 강도 3 미만 기준 피크는 제외합니다. 기준 피크의 강도 내림차순으로 한 관찰 피크에 한 번씩 대응시킵니다.

점수 = 100 × (0.65 × 기준 강도 가중 일치율 + 0.35 × 관찰 피크 강도 설명률).

기준 피크의 강도 가중치는 위치 오차 e와 허용 오차 t에 따라 (1−e/(2t))를 곱합니다. 비일치 피크는 분자에 포함하지 않습니다. 측정 높이와 기준 상대 강도를 사용하는 휴리스틱이며 정답 확률·상 함량·Rietveld 적합도가 아닙니다. 영점 이동의 자동 최적화는 제공하지 않습니다. 여러 후보가 나와도 다상 조합의 식별을 의미하지 않습니다.

## Williamson–Hall

기기 폭이 입력됐고 최상위 후보에 대응하는 유효 피크가 3개 이상일 때만 βcosθ = Kλ/D + 4εsinθ를 선형 회귀합니다. 양의 절편, 음수가 아닌 기울기, R²≥0.8일 때 탐색 결과를 표시합니다. 상 귀속, 등방성, Gaussian FWHM 사용에 의존하며 일반적인 line-profile 모델을 대체하지 않습니다. 회귀 그래프와 이유를 반환합니다. 통계적 신뢰구간이나 ASTM 적합성을 주장하지 않습니다.

## SEM

이미지 하단에서 지속적인 극단 밝기 배경으로 전환되는 수평 경계를 정보 바 후보로 추정합니다. 정보 바 또는 하단 20%에서 긴 수평 밝은/어두운 선을 스케일바 후보로 찾습니다. 문자 OCR이나 자동 실제 길이 판독은 하지 않습니다. 사용자 확인과 수동 두 점 보정을 우선합니다. 좌표와 픽셀 길이는 원본 해상도 기준입니다.

Gaussian 노이즈 완화 → Otsu 이진화 → 구멍 채움 → 거리 변환 → 국소 최대 마커 → Watershed. 가장자리 객체와 최소 면적 미만 객체, 사용자 제외 ID는 통계에서 제외합니다. 번호는 원본 라벨 ID이며 연속적이지 않을 수 있습니다. 마커 간격은 픽셀 단위로 조절합니다. 겹친 입자 분리 정확도는 형태와 대비에 따라 달라집니다.

직경은 √(4A/π), 장·단축은 영역의 타원 근사, 원형도는 4πA/P²이며 P는 Crofton 둘레 근사입니다. 픽셀 이산화로 원형도가 1을 약간 넘을 수 있어 원시 결과를 보존하고 경고합니다. 종횡비는 장축/단축입니다. D10·D50·D90은 개수 기준 등가원 직경의 백분위, 표준편차는 모집단 정의(ddof=0)입니다. 표본이 0이면 통계는 null입니다. 길이 스케일을 두 배로 하면 면적은 네 배가 됩니다. 미확인 스케일은 px/px²입니다.

SEM 결과는 2D 시야의 관찰 분포입니다. 실제 벌크 3D 입도, 결정립 또는 결정상으로 자동 해석하지 않습니다. 분할 확인 전 결과는 잠정 통계입니다.

## 재현성 및 운영

실행별 원본 SHA-256, CIF SHA-256, 입력 조건, 라이브러리 버전, 알고리즘 버전, 결과와 UTC 생성 시각을 저장합니다. 화면에서는 브라우저 현지 시각을 표시합니다. 과거 실행은 불변이며 설정 변경 시 새 실행이 필요합니다. 서버 재시작으로 중단된 작업은 실패 상태로 바뀌며 자동 재시도하지 않습니다. 기본 파일 제한 20MB, CIF 1MB, CSV 30,000행, 이미지 16M 픽셀, 피크 200개입니다.
