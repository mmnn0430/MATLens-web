# MatLens 검증 결과 및 구현 현황 보고서

본 문서는 `backend/tests/test_matlens_full.py` (`pytest` 7개 통합 시나리오 전수 통과) 및 `backend/scripts/run_verification.py`를 실제로 실행하여 측정한 검증 결과와 허용 오차, 실패 조건 처리, 구현 범위를 정리한 보고서입니다.

---

## 1. 검증 범위의 구분

1. **합성 기준 데이터 검증 (Synthetic Ground-Truth Verification)**:
   - 정확한 피크 위치·선폭·결정자 크기·미세변형률 및 원형 입자 반경·개수를 수식으로 부여한 데이터에 대해 알고리즘의 복원 정확도를 정량 검증했습니다.
2. **공개 결정구조 표준 데이터 검증 (Public Reference Structure Verification)**:
   - 미국 NIST SRM 640f 실리콘 표준 격자상수($a = 5.43119\,\text{\AA}$) 기준 회절선 및 Crystallography Open Database 공개 파일(`cod_9009086_anatase.cif`, `cod_9004141_rutile.cif`)의 실시간 파싱·매칭을 검증했습니다.
3. **실제 시료 데이터 적용 시 추가 고려 범위 (Real-Sample Scope)**:
   - 실제 장비 측정 데이터에서는 $K\alpha_1 / K\alpha_2$ 고각 이중선 분리, 시편 높이 오차($\cos\theta$ 비례 이동), 우선배향(texture)에 의한 상대강도 변화, SEM 시료 대전(charging) 및 3차원 중첩이 추가로 작용할 수 있습니다. MatLens는 고각 피크($>65^\circ$) 자동 제외, 영점 이동 탐색, 사용자 수동 피크/객체 제외 기능으로 이를 보조하되, 정밀 상분율이나 인증 입도 분석을 대체하지 않음을 명시합니다.

## 2. 실제 수행한 정량 검증 결과 (`docs/verification_metrics.json`)

### 2.1 XRD 피크 위치 · 선폭 · 평활화 불변성 검증
- **NIST SRM 640f 기준 실리콘 패턴 (6개 반사선, 포아송 노이즈 포함)**:
  - 상 매칭 1순위: `Silicon (Si, NIST SRM 640 기준계)` (`REF-SI-DIA`, 매칭 점수 `96.4 / 100`)
  - 피크 위치 및 비평활 Pseudo-Voigt FWHM 복원 오차 (허용 오차 기준: $|\Delta 2\theta| \le 0.02^\circ$, $|\Delta \text{FWHM}| \le 0.015^\circ$):
    - `(111)`: 참값 `28.4411°` / 측정 `28.4417°` ($|\Delta 2\theta| = 0.0006^\circ$), 참값 FWHM `0.1606°` / 측정 `0.1598°` ($|\Delta w| = 0.0008^\circ$)
    - `(220)`: 참값 `47.3004°` / 측정 `47.3008°` ($|\Delta 2\theta| = 0.0004^\circ$), 참값 FWHM `0.1687°` / 측정 `0.1671°` ($|\Delta w| = 0.0016^\circ$)
    - `(311)`: 참값 `56.1195°` / 측정 `56.1206°` ($|\Delta 2\theta| = 0.0011^\circ$), 참값 FWHM `0.1743°` / 측정 `0.1737°` ($|\Delta w| = 0.0006^\circ$)
    - `(400)`: 참값 `69.1264°` / 측정 `69.1255°` ($|\Delta 2\theta| = 0.0009^\circ$), 참값 FWHM `0.1854°` / 측정 `0.1862°` ($|\Delta w| = 0.0008^\circ$)
    - `(331)`: 참값 `76.3723°` / 측정 `76.3699°` ($|\Delta 2\theta| = 0.0024^\circ$), 참값 FWHM `0.1933°` / 측정 `0.1930°` ($|\Delta w| = 0.0003^\circ$)
    - `(422)`: 참값 `88.0250°` / 측정 `88.0251°` ($|\Delta 2\theta| = 0.0001^\circ$), 참값 FWHM `0.2096°` / 측정 `0.2119°` ($|\Delta w| = 0.0023^\circ$)
- **검출/정량 분리 검증**: Savitzky–Golay 평활화(`window=15`) 활성 시와 비활성 시 정량 FWHM 차이가 `< 0.0001°`로 선폭 왜곡이 완전히 차단됨을 확인했습니다.
- **다상 TiO2 (Anatase + Rutile) 및 공개 COD CIF 검증**:
  - 단일상(`Anatase`) 패턴 잔차 `R_pat = 0.2801` 대비 2상 조합(`Anatase + Rutile`) `R_pat = 0.1330`으로 잔차 **52.5% 감소** 확인.
  - 기기 선폭 보정(`0.08°`) 시 Scherrer 평균 `27.9 nm` vs 미입력 시 `25.3 nm` 및 **`기기 선폭 미보정 추정값`** 배지 자동 전환 확인.
  - 공개 `cod_9009086_anatase.cif` 업로드 시 `TiO2` (`I4_1/amd`) 정상 파싱 및 매칭(`77.7점`) 확인.

### 2.2 SEM 합성 도형 및 입자 · 결정립 정량 검증
- **단일 크기 원형 디스크 검증 (`r = 25 px`, `100 px = 200 nm` $\Rightarrow$ 참값 직경 `100.0 nm`, `N = 6`)**:
  - 검출 객체 수: `6 / 6`개 일치
  - 평균 등가원 직경: `101.55 nm` (래스터 픽셀 이산화 오차 `+1.55%`, 허용 오차 $\pm 5\%$ 이내), 원형도 중앙값 `0.936`
  - 스케일을 `100 px = 400 nm`로 수정 재실행 시 평균 직경이 정확히 `2.00배`(`203.10 nm`)로 재계산됨을 검증했습니다.
- **다분산 접촉 나노입자 검증 (`sample_tio2_particles_sem.png`, `200 px = 500 nm`, `N = 145`)**:
  - Watershed 분리 객체 수: `145 / 145`개
  - 개수 기준 평균 직경: 참값 `116.30 nm` vs 측정값 `113.27 nm` (상대 오차 `-2.6%`)
  - 개수 기준 `D50`: 참값 `116.98 nm` vs 측정값 `113.72 nm` (상대 오차 `-2.8%`), 면적 가중 `D50 = 123.54 nm` 별도 산출 확인
- **결정립 선형교차법 검증 (`sample_sintered_grains_sem.png`, `200 px = 5 µm`)**:
  - 다방향 시험선 총 길이 `166.74 µm`, 유효 경계 교차 `125회` $\rightarrow$ 평균 선형교차 길이 `1.33 µm` 산출 및 수동 교차점 편집 시 즉시 반영 확인.

### 남은 향후 고도화 항목 (미구현 항목 — 완료로 가장하지 않고 명시)
- [ ] **전체 프로파일 Rietveld 정밀화 및 RIR 정량 상분율(wt%) 계산**: 현재 다상 비교는 패턴 잔차 감소 확인용이며, 원자 좌표·배향성·미소흡수를 포함한 정량 질량분율 산출은 향후 확장 대상입니다.
- [ ] **이방성 Williamson–Hall (UDSM / UDEDM) 및 Warren–Averbach 푸리에 선폭 해석**: 결정 방향별 탄성계수 텐서를 요구하는 고도화 모델입니다.
- [ ] **SEM 스케일바 텍스트 OCR 자동 숫자 판독**: 현재는 오판독 위험을 막기 위해 스케일바 선분(px)만 자동 탐지하고 숫자와 단위는 사용자가 직접 확인·입력하도록 설계되어 있습니다.
- [ ] **딥러닝 인스턴스 세그멘테이션(심하게 중첩된 3D 비구형 응집체 분리)**: 현재는 고전 영상처리(CLAHE + EDT + Marker-controlled Watershed)와 사용자 수동 객체 제외 방식을 사용합니다.
